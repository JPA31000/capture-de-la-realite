# La capture de la réalité

Cours interactif pour les élèves de génie civil (lycée professionnel, Campus BTP) : pourquoi capturer la réalité d’un bâtiment existant, le drone (photogrammétrie, inspection thermique, inspection technique), le scanner 3D Trimble X7 et l’insertion d’un nuage de points dans Revit.

- **5 parties** pour une séance de 2 heures, 7 schémas à manipuler, un quiz de 8 questions.
- **8 vidéos** du diaporama (captures d’écran, sans son), d’abord dans l’écran d’un ordinateur portable dessiné, avec un bouton **Plein écran**.
- **Mode présentation** pour projeter en classe (touche **P**).
- Une seule page, `index.html`, et le dossier `videos/` (46 Mo : les vidéos et leurs affiches). Elle s’ouvre dans un navigateur, sans compte ni serveur ; la progression reste sur l’ordinateur de l’élève.

Source : diaporama « Diagnostic technique » (CMQE BTP et usages du numérique, Occitanie).
